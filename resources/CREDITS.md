# Credits

This folder is filled on your machine by `tools/sync_packages.py` and isn't published: the
repository contains none of these files.

- **Magic Set Editor packages** in `mse_packages/` come from the
  [MagicSetEditorPacks Full Magic Pack](https://github.com/MagicSetEditorPacks/Full-Magic-Pack)
  and keep their original authors' credits (see each package's main file).
- Some template images in that pack are provided by [CardConjurer](https://cardconjurer.com/).
- **Fonts** in `fonts/` come from the same pack's "Magic - Fonts" folder. Fonts have varied
  licenses (several are commercial), which is why they aren't published.
- Magic: The Gathering, its card frames and mana symbols are property of Wizards of the Coast.
