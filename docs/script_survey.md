# MSE script survey

Generated by `tools/survey_scripts.py`. Rough lexical scan of every script in `magic.mse-game` (all files it includes), the symbol fonts our styles depend on, and the five target styles (magic-m15-altered, magic-old, magic-new, magic-veryold, magic-old-abu), after include expansion. Counts are approximate.

**Built-in** = called as `f(...)` or `f@(...)` but never defined with `:=` anywhere in the corpus, so MSE itself must provide it. **Reachable** = used by a style directly or through game-script functions it references.

Not scanned: the game's 380 `keyword` definitions (reminder-text templates such as `{param1}: Attach to ...`); they matter for the mechanics feature, not rendering.

See `docs/interpreter_stages.md` for the build order drawn from this report.
